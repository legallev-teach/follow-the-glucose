# Follow the Glucose
HSB study activity for Form 4 and Form 5 (CUCSS).
Students follow one glucose molecule: sunlight → leaf → food chain → plate → villi → cell → back to the leaf.

- Student link: https://legallev-teach.github.io/follow-the-glucose/
- Teacher mode: add #teacher to the link (all stations open, test tools, code checker)
- Results go to the "HSB – Follow the Glucose (Results)" Google Sheet.
